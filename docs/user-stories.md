User Stories 1-4

1. As a User, I want to manually input my monthly income into the main balance, so that I can see the total amount of money available to spend.
2. As a User, I want to see a summary of my current total balance on the home dashboard, so that I can quickly check my financial status as soon as I open the app.
3. As a User, I want to filter my transaction history by date range (e.g., this week or this month), so that I can review my financial activities for a specific period.
4. As a User, I want to edit the amount or details of a previous transaction, so that I can correct any typing mistakes to keep my balance records accurate.
