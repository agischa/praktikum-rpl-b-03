### US-01
As a User, I want to manually input my monthly income into the main balance, so that I can see the total amount of money available to spend.

Acceptance Criteria:
- Given user is on the dashboard
- When user inputs monthly income data
- Then system adds the income to the main balance


### US-02
As a User, I want to see a summary of my current total balance on the home dashboard, so that I can quickly check my financial status as soon as I open the app.

Acceptance Criteria:
- Given user has transaction data
- When user opens the home dashboard
- Then system displays the current total balance


### US-03
As a User, I want to filter my transaction history by date range (e.g., this week or this month), so that I can review my financial activities for a specific period.

Acceptance Criteria:
- Given user has transaction history
- When user selects a date range filter
- Then system displays transactions within the selected period


### US-04
As a User, I want to edit the amount or details of a previous transaction, so that I can correct any typing mistakes to keep my balance records accurate.

Acceptance Criteria:
- Given user has existing transaction data
- When user edits a transaction
- Then system updates the transaction data correctly


### US-05
As a User, I want to categorize my daily expenses, so that I can view my spending clearly in a percentage chart.

Acceptance Criteria:
- Given user inputs expense data with categories
- When user opens the statistics page
- Then system displays expense percentages by category


### US-06
As a User, I want to allocate my main balance into a specific "Brankas", so that I can save money for specific goals like marriage or umrah.

Acceptance Criteria:
- Given user has sufficient main balance
- When user allocates money to a Brankas
- Then system reduces main balance and adds to Brankas balance

### US-07
As a User, I want my "Brankas" balance to be isolated from regular transactions, so that my savings are safe from accidental spending.

Acceptance Criteria:
- Given user has Brankas balance
- When user performs regular transactions
- Then Brankas balance remains unchanged

### US-08
As a User, I want to see a progress indicator on my saving goals, so that I know how much more money I need to collect.

Acceptance Criteria:
- Given user has a saving target in Brankas
- When user views the saving progress
- Then system displays the percentage of progress towards the goal
